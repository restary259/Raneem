## Formal Bagrut access baseline

The Team Majors records separately store the official general Israeli Bagrut access rule used in the intelligence system:

- Mathematics: 3 units
- English: 4 units
- One further subject: 4 units

The planning benchmark must never replace this formal access rule or a university's programme-specific admission procedure.

### Route exception

Culinary Arts is deliberately **not** assigned a DARB Bagrut planning benchmark. The internal research classifies Culinary Arts as an **Ausbildung** route rather than a university degree, so the university-oriented benchmark should not appear for it. The current university reference in the intelligence dataset is retained only as an explicitly labelled adjacent food-science route, not as a Culinary Arts degree.

The Bundesagentur für Arbeit's current Ausbildung search lists Koch/Köchin as a Berufsausbildung, supporting the route classification used for this exception.
