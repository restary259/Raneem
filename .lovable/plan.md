# Unified bright photo heroes with centered dark panel

## Scope
Match the attached reference across every public **photo-backed hero**. Keep each page’s existing text, buttons, route, and page-specific photograph, while standardizing the hero presentation. Plain openings without a full-width hero photo, such as Contact and the AI Advisor tool, remain structurally unchanged.

## Changes
1. **Standardize the shared photo hero**
   - Update the shared photo hero used by Apply, Educational Programs, Educational Destinations, Services, Who We Are, FAQ, Blog, Resources/tools, Partnership, Locations, and legal pages.
   - Keep the photograph full-bleed, naturally bright, and recognizable by removing broad dark/color washes from the image itself.
   - Place the copy and actions in one centered, square-cornered black panel with semi-transparent opacity, matching the reference rather than a light card.
   - Use white primary copy, restrained secondary copy, and existing brand accents/buttons with accessible contrast.

2. **Match the homepage opening hero**
   - Give the homepage hero the same centered black semi-transparent panel treatment and bright full-width photograph.
   - Align its width, spacing, text hierarchy, and actions with the reference while retaining the current DARB content and responsive type system.
   - Preserve the bottom spectrum strip.

3. **Homepage arch behavior**
   - Keep the rainbow arch in the homepage opening hero on mobile only.
   - Hide that opening arch at tablet and desktop widths.
   - Do not change rainbow accents elsewhere on the homepage or other pages.

4. **Responsive behavior**
   - Size the panel with bounded fluid width and padding so it remains centered without becoming a full-screen card.
   - Allow headings, descriptions, and actions to wrap cleanly at narrow widths.
   - Keep hero heights responsive to short phones, tablets, laptops, and wide screens without cropping the panel or causing horizontal overflow.

5. **Visual verification**
   - Check the homepage and representative shared heroes in Arabic and English.
   - Verify mobile, tablet, short desktop, and wide desktop sizes for bright imagery, centered panel alignment, text fit, navigation clearance, and the homepage-only mobile arch rule.
   - Confirm all photo-hero routes inherit the shared treatment and run the existing validation checks.

## Technical boundaries
- Presentation-only changes to the homepage hero, shared photo hero, and their responsive styles.
- No changes to page copy, page-specific image selection, navigation behavior, forms, AI behavior, authentication, backend, or business logic.
